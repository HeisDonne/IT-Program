## Git Note

## Objective

To understand what Git is, why it is used, and how it helps track and manage changes in a project.

## What is it?
Git is a distributed version control system that records changes made to files over time. It allows developers to track project history, collaborate with others, and restore previous versions when necessary.

## Why do we use it?
Git helps developers:

- Keep track of changes made to files.
- Work on projects without overwriting each other's work.
- Restore previous versions if mistakes are made.
- Collaborate with teams efficiently.
- Maintain a complete history of a project.

## Key Concepts
### Repository
A repository (repo) is a folder that Git uses to track files and their history.

### Commit

A commit is a snapshot of the project at a specific point in time. Each commit has a unique ID and a message describing the changes made.

### Branch

A branch is an independent line of development. During this week, I worked on the `main` branch.

### Remote Repository

A remote repository is a copy of the project hosted on another computer or platform such as GitHub.

### GitHub

GitHub is a cloud platform used to host Git repositories, making collaboration and backup easier.

## Real-World Applications
Git is used by software developers, DevOps engineers, system administrators, and IT teams to manage projects, collaborate with others, maintain version history, and safely deploy updates.

## What I Learned
I learned that Git does not automatically save changes. Files must first be staged and then committed before they become part of the project's history. I also learned how to connect a local repository to GitHub and push commits using SSH.
