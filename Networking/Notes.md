# Topic
Networking 

## What is it?
Networking is the process of connecting two or more computers or devices so they can communicate and exchange information. 

A netowrk allows devices to send data, Receive data, Share resources, Access services. 
## WHo sends data? And who respond?
A client is a device or program that requests a service 
A server is a device or program that Provides a service. 

On order for these devices to send data, receive data. THey need to extablish a connection.

## IP Address
An Ip Address is a unique address assigned to a device on a network. It allows devices to identify and communicate with each other. 
It's like an house address for a computer. It tells other devices where to send information. 

## Types of IP address
1. Private IP Address: Used inside local networks.
2. Public IP Address: Used on the internet. 

Now the IP address is what computer uses to locate a server or request destination. Human requests uses name; Domain names e.g github.com

## DNS (Donain Name System)
 DNS converts domain names into IP addresses

DNS Process:
1. User enters github.com 
2. Computer ask DNS for github.com IP address
3. DNS responds with the IP addrress
4. The computer can now connect to github.com. 

In Summary, when I open a website; 
My computer first uses DNS to translate the website name into an IP address. After getting the IP address, my computer checks the routing table to know where to send the packets. If the destination is outside my local network, the packets are sent to the router gateway. The server receives the request and sends a response back to my computer.
