# Active Directory

## Definition

Active Directory (AD) is Microsoft's directory and identity-management system used mainly in Windows environments.

It allows organizations to centrally manage users, computers, groups, permissions, and authentication.

## What Active Directory Is Used For

An organization can use Active Directory to manage:

* User accounts
* Computer accounts
* Groups
* Permissions
* Authentication
* Security policies

Instead of managing every computer and user separately, an administrator can manage them centrally.

## Domain Controller

A Domain Controller (DC) is a server that runs Active Directory Domain Services (AD DS).

It handles important functions such as authenticating users and managing information about users and computers in the domain.
