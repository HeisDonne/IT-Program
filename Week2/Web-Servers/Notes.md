# Web Servers

## Definition

A web server is software that receives requests from clients, usually through HTTP or HTTPS, and sends back web content or other responses.

For example, when a user visits a website, the browser sends a request to a web server. The server processes the request and sends a response back.

## Nginx

Nginx is a web server that can serve websites and web applications. It is also commonly used as a reverse proxy and load balancer.

I used Nginx during the Week 2 practical by running it inside a Docker container.

## Apache

Apache HTTP Server is another popular web server used to serve websites and applications.

Both Nginx and Apache can handle HTTP and HTTPS requests.

## HTTP and Web Servers

When a browser requests a webpage, it sends an HTTP request to the web server.

For example:

```
GET / HTTP/1.1
```

The web server then sends an HTTP response.

A successful response may be:

```HTTP/1.1 200 OK
```
