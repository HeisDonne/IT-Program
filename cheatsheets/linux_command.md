| Command  | Full Meaning                                  | What it Does                                                         | Example           |
| -------- | --------------------------------------------- | -------------------------------------------------------------------- | ----------------- |
| `pwd`    | Print Working Directory                       | Shows your current directory (where you are in the file system).     | `pwd`             |
| `ls`     | List                                          | Lists files and folders in the current directory.                    | `ls`              |
| `cd`     | Change Directory                              | Moves you into another directory.                                    | `cd Documents`    |
| `cd ..`  | Change Directory (Parent)                     | Moves up one directory level.                                        | `cd ..`           |
| `cd ~`   | Home Directory                                | Takes you directly to your home directory.                           | `cd ~`            |
| `cd`     | Change Directory                              | Also takes you to your home directory when used without an argument. | `cd`              |
| `mkdir`  | Make Directory                                | Creates a new folder.                                                | `mkdir Week1`     |
| `touch`  | *(Originally used to update file timestamps)* | Creates a new empty file if it doesn't exist.                        | `touch notes.txt` |
| `nano`   | Nano Text Editor                              | Opens a file for editing in the terminal.                            | `nano notes.txt`  |
| `cat`    | Concatenate                                   | Displays the contents of a file in the terminal.                     | `cat notes.txt`   |
| `rm`     | Remove                                        | Deletes a file.                                                      | `rm notes.txt`    |
| `rmdir`  | Remove Directory                              | Deletes an empty directory.                                          | `rmdir Practice`  |
| `rm -r`  | Remove Recursively                            | Deletes a directory and everything inside it.                        | `rm -r Practice`  |
| `whoami` | Who Am I                                      | Displays the username of the currently logged-in user.               | `whoami`          |
| `mv`     | Moves or renames files and folders.                                                                                  |`mv notes.txt notes.md` |
| `mv`     | Moves a file into another folder.                                                                                    |`mv notes.md Notes/`|
|`echo`    | Prints texts into a file. the >> append to the notes, Not overwriting it.                                            |`echo "Hi" >> note.md"`|                   |
| `tree`   | Shows folders in a tree structure
| `cp`     | copy files                                                                                                                                |
| `head`   | show the beginning of a file                                                                                                              |
| `tail`   | show the end of a file                                                                                                                    |
